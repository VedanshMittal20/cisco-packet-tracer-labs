Experiment 1.1: Core Viva Exam Questions

1. What are the IP Classes?

  • Class A: 1 - 126 (Mask: 255.0.0.0)
  • Class B: 128 - 191 (Mask: 255.255.0.0)
  • Class C: 192 - 223 (Mask: 255.255.255.0)
  • (127.0.0.0 is loopback address)

2. What is the difference between Straight and Cross-over cable?

  • Straight-Through: Connects unlike devices (PC to Switch, Switch to Router).
  • Cross-Over: Connects like devices (PC to PC, Router to Router, PC to Router).

3. What are the Router memory components?

  • RAM: Volatile; holds running-config and routing tables.
  • NVRAM: Non-volatile; holds startup-config.
  • Flash: Holds Cisco IOS operating system images.
  • ROM: Bootstrap program and POST diagnostics.

Master Viva Voce Guide (All 30 Exam Questions & Answers)

Also available as Markdown: ALL_VIVA_QUESTIONS_AND_ANSWERS.md

1. OSI & Network Basics

  • 7 Layers of OSI: Physical (Bits), Data Link (Frames), Network (Packets), Transport (Segments), Session, Presentation, Application (Data).
  • TCP vs UDP: TCP is connection-oriented, reliable (3-way handshake SYN, SYN-ACK, ACK), slower. UDP is connectionless, best-effort, no handshake, lightweight.
  • Collision vs Broadcast Domain: Hub has 1 collision & 1 broadcast domain. Switch has 1 collision domain per port, 1 broadcast domain total. Router separates both collision and broadcast domains on every port.

2. Devices & Cabling (Exp 1.1)

  • Hub vs Switch vs Router: Hub is Layer 1 (repeats to all ports, half-duplex). Switch is Layer 2 (MAC address learning, unicast forwarding, full-duplex). Router is Layer 3 (routes packets between different subnets using IP).
  • Straight-Through vs Cross-Over: Straight-through connects unlike devices (PC-to-Switch, Switch-to-Router). Cross-over connects like devices (Router-to-Router, PC-to-PC, PC-to-Router).
  • Router Memory: RAM (volatile, running-config), NVRAM (permanent, startup-config), Flash (Cisco IOS image), ROM (Bootstrap, POST).
  • IP Classes: Class A (1-126, mask 255.0.0.0), Class B (128-191, mask 255.255.0.0), Class C (192-223, mask 255.255.255.0), 127 is loopback.

3. Command Prompt Commands (Exp 1.2)

  • Ping protocol: Uses ICMP (Internet Control Message Protocol), Type 8 (Echo Request), Type 0 (Echo Reply). Does NOT use TCP/UDP ports.
  • TTL (Time To Live): 8-bit hop counter (max 255) decremented by 1 at each router to prevent infinite routing loops. Drops at 0 with ICMP Type 11 (Time Exceeded).
  • How Tracert works: Sends packets starting with TTL=1, then TTL=2, etc., causing intermediate routers to return ICMP Time Exceeded until the destination is reached.
  • ARP: Address Resolution Protocol. Maps Layer 3 IP address to Layer 2 physical MAC address. arp -a displays local cache.
  • ipconfig vs ipconfig /all: ipconfig shows basic IP/Mask/Gateway. /all shows MAC, DHCP server, DNS server, lease info.

4. Hub vs Switch (Exp 1.3)

  • Why Hubs are insecure: They broadcast all traffic to all ports; any host in promiscuous mode can capture all conversations.
  • How a Switch learns: Reads the Source MAC of incoming frames to populate its CAM/MAC table, then forwards unicast based on Destination MAC. Floods unknown unicast.
  • Command: show mac address-table

5. Static Routing (Exp 1.4)

  • Static Route Syntax: ip route <dest-network> <subnet-mask> <next-hop-ip>
  • Administrative Distance (AD): Priority/trustworthiness of a route (lower is preferred). Connected = 0, Static = 1, RIP = 120.
  • Default Route: ip route 0.0.0.0 0.0.0.0 <next-hop> (Gateway of Last Resort).
  • Floating Static Route: Static route given a higher AD (e.g., 130) as a backup for a dynamic route.

6. Dynamic Routing & RIP (Exp 1.5)

  • RIP Characteristics: Distance Vector protocol, Bellman-Ford algorithm, metric is Hop Count (Max 15, 16 is infinity/unreachable), AD is 120, UDP port 520, updates sent every 30 seconds.
  • RIPv1 vs RIPv2: RIPv1 is classful, broadcasts to 255.255.255.255, no VLSM. RIPv2 is classless, multicasts to 224.0.0.9, supports VLSM/CIDR, supports MD5 authentication.
  • Loop Prevention: Split Horizon (don't advertise route back out incoming port), Route Poisoning (set metric to 16 immediately on failure), Poison Reverse, Holddown Timers.
  • Why Clock Rate? Serial DCE interfaces must provide clocking synchronization pulses for the DTE end. Configured with clock rate 64000.
